# Electro_Scan_Pro v12.2 (GitHub Actions APK + Logo)

Projek lengkap untuk membina APK Android secara automatik di GitHub Actions bersama ikon aplikasi rasmi.

## Struktur Fail
- `www/index.html` — Aplikasi Electro_Scan_Pro v12.2.
- `assets/icon-only.png` — Logo aplikasi 1024x1024 PNG.
- `scripts/patch-android.js` — Skrip kebenaran Kamera, Mikrofon, Galeri & Internet.
- `.github/workflows/build-apk.yml` — Aliran kerja GitHub Actions (termasuk jana ikon automatik).
- `package.json` & `capacitor.config.json` — Konfigurasi Capacitor Android.
